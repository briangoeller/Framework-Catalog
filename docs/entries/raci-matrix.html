RACI Matrix ⚑

tool · management · organizing-schema

Clarifies who is Responsible, Accountable, Consulted, and Informed for each task.

The RACI Matrix is a responsibility-assignment chart that maps tasks or deliverables (rows) against people or roles (columns), with each cell marked Responsible (does the work), Accountable (single owner who answers for the outcome), Consulted (provides input before the work), or Informed (kept up-to-date after decisions). The framework's core discipline is that each task must have exactly one Accountable owner (eliminating diffuse responsibility) but may have multiple Responsibles and Consulted/Informed parties. RACI emerged in project management practice in the 1970s-80s with no clear single-author origin, becoming a standard tool in PMBOK and ITIL guidance. Numerous variants exist: RASCI (adding Support), RACI-VS (adding Verifier and Signatory), DACI (Driver-Approver-Contributors-Informed for decisions), and RAPID (Bain's variant: Recommend-Agree-Perform-Input-Decide).

Core components

  • Tasks (rows) x roles (columns)
  • Responsible (does the work)
  • Accountable (single owner)
  • Consulted (input provided before decision)
  • Informed (kept aware after decision)
  • Single-Accountable rule
  • Variants (RASCI, RACI-VS, DACI, RAPID)

Primary use case

Project responsibility assignment and role clarification; cross-functional initiative governance; preventing diffuse accountability; structuring team conversations about work ownership; foundational artifact in project-management documentation.

Common criticisms

  • Single-Accountable rule frequently violated in practice without consequence
  • can become bureaucratic documentation disconnected from actual work flow
  • static snapshot that doesn't capture how responsibility shifts over project phases
  • risk of overassignment of 'Consulted' and 'Informed' that diffuses focus
  • doesn't address decision-making authority cleanly (driving DACI and RAPID variants)
  • can substitute for genuine cross-functional collaboration
  • large RACI matrices for complex programs become unwieldy
  • cells often filled in by exception or politely rather than by genuine analysis.
